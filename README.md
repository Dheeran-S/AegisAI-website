# AegisAI 2027 Conference Website

AegisAI 2027 is the official website for the **International Conference on AI-Driven Secure and Intelligent Systems**, hosted by Shiv Nadar University Chennai (25–27 March 2027).

This repository contains the full source code for the conference website, including a dynamic frontend and a custom-built Content Management System (CMS) admin panel powered by Node.js, Express, and MySQL.

## 🚀 Features

- **Dynamic Frontend**: Pages are rendered dynamically from the database based on customizable slugs and section types.
- **Admin Dashboard**: A built-in CMS for administrators to:
  - Create, edit, and manage pages and their sections.
  - Manage global website settings.
  - View and manage contact form submissions.
- **Secure Authentication**: JWT-based authentication for the admin panel using bcrypt for password hashing.
- **Responsive Design**: Custom CSS (Vanilla HTML/CSS/JS) ensuring a seamless experience across all devices.
- **Database Driven**: Uses MySQL (compatible with TiDB Serverless) to store pages, sections, admins, contacts, and settings.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MySQL (TiDB Cloud)
- **Authentication**: JSON Web Tokens (JWT), bcryptjs
- **Deployment**: Vercel (Configured with `vercel.json` and serverless functions)

## 📂 Project Structure

```text
AeginAI/
```

## ⚙️ Prerequisites

- **Node.js** (v14 or higher)
- **MySQL** database (Local or Cloud like TiDB/PlanetScale)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <your-repo-url>
cd aegisai-conference
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Environment Variables

Create a `.env` file in the root directory based on the following template:

```env
DB_HOST=your_mysql_host
DB_PORT=your_mysql_port
DB_USER=your_mysql_user
DB_PASSWORD=your_mysql_password
DB_NAME=aegisai_conf

JWT_SECRET=your_super_secret_jwt_key
JWT_EXPIRES_IN=8h
PORT=3000
```

*(Note: To connect securely to managed cloud databases like TiDB, ensure you use the correct host and SSL configurations).*

### 4. Database Setup

You can set up the initial database schema using the provided `schema.sql` file.

To automatically create tables and insert seed data (default admin user, initial pages, and settings), run:

```bash
npm run seed
```

*Note: The default admin credentials generated by the seed script are:*
- **Email:** `admin@aegisai.org`
- **Password:** `Admin@1234`

### 5. Run the Application

**Development Mode (with nodemon auto-reload):**
```bash
npm run dev
```

**Production Mode:**
```bash
npm start
```

### 6. Access the Application

- **Public Website**: `http://localhost:3000`
- **Admin Panel**: `http://localhost:3000/admin/login.html`
